# 坦克大战（Tank Battle）

自包含、无外部依赖的网页小游戏：绿色为玩家坦克，红色为敌方坦克，砖墙提供掩体。
玩法目标是在守住生命的前提下击毁不断推进的敌方坦克换取更高得分。

## 游戏玩法

- 敌方坦克从顶部定时刷新（间隔约 2 秒，场上最多 5 台），自动追踪玩家所在列并向下推进、开火。
- 控制玩家坦克移动并射击，击毁一台敌方坦克得 **100 分**（右上角显示）。
- 初始 **3 条生命**：被敌方子弹击中会扣 1 条，并触发短暂无敌闪烁。
- 生命归零即游戏结束，弹出最终得分。

## 操作键位

| 操作 | 键位 |
| --- | --- |
| 移动 | 方向键（↑ ↓ ← →）或 WASD |
| 射击 | 空格（Space） |
| 重新开始（游戏结束后） | R 键，或点击画面上的「重新开始」按钮 |

## 启动方式

任选其一（均无需安装依赖，项目不引用任何外部 CDN）：

1. **直接打开（最简单）**：用浏览器双击打开 `index.html` 即可游玩。
2. **Python 静态服务器**（需 Python 3）：
   ```bash
   python -m http.server 8000
   ```
   然后浏览器访问 <http://localhost:8000/>
3. **npx serve**（需 Node.js）：
   ```bash
   npx serve .
   ```
   然后浏览器访问终端提示的本地地址。

> 使用本地服务器启动（方式 2/3）时，请确认当前工作目录是 `demo/tank-game/`，
> 直接双击打开（方式 1）则无需任何服务器。

## 验收步骤

1. **能看到画布**：打开后画面中央出现 15x13 的战场（深色背景、砖墙、绿色玩家坦克）。
2. **能移动**：按方向键 / WASD，绿色坦克随之移动，且会被砖墙挡住。
3. **能射击**：按空格，玩家坦克前方朝上射出黄色子弹。
4. **能杀伤敌方**：移动瞄准后射击，命中红色坦克即消失，右上角得分增加 100，随后顶部补刷新敌方坦克。

以上任一步骤失败都视为未通过验收。
